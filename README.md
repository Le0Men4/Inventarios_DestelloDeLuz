# Inventarios_DestelloDeLuz

Sistema integral y multiplataforma de gestión de inventarios, formulaciones y control de producción diaria para taller artesanal de velas y productos aromáticos (Destello de Luz).

## Características principales
- **Gestión de Materia Prima e Insumos**: Ceras, esencias, envases, pabilos y adornos con alertas visuales de stock mínimo y trazabilidad de movimientos.
- **Fórmulas y Fichas Técnicas**: Soporte para productos estándar (un solo vertido) y velas multicapa / de postre (con capas, colores, gramajes y temperaturas de vertido).
- **Colecciones de Temporada y Fuera de Temporada**: Capacidad de pausar y reactivar líneas completas de temporada fácilmente con filtros independientes.
- **Plan Diario y Producción**: Checklist interactivo por trabajador para el día, notas de advertencia del taller y descontado automático de existencias.
- **Protección de Acceso**: Control mediante PIN de taller de 6 dígitos con sesiones activas de 4 horas y selección de perfiles de operador.
- **Despliegue Seguro**: Configurable mediante variables de entorno (`APP_PIN`) para despliegue en la nube (Render).
